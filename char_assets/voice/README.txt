キャラボイスのファイル置き場（星めぐりに願いを）

■ ファイル名のルール
  char_assets/voice/<キャラID>_<場面><番号>.mp3
  場面は5種類、番号は1〜4（各場面4つずつ）

  select ＝ キャラ選択で決定した時
  plus   ＝ プラスマスなどでリスナーが増えた時
  minus  ＝ マイナスマスなどでリスナーが減った時
  stolen ＝ 星のカケラを取られた時
  guard  ＝ 星のカケラを金盾・銀盾で守った時

  例）氷室うつろの「カケラを取られた時」2つ目 → utsuro_stolen2.mp3

■ キャラID一覧
  mikado=帝 / hikari=神乃ひかり / sakura=餅々さくら / nemea=伊織ねめあ
  rui=魔昏るい / tefu=馬鹿蝶 / heru=碧衣ヘル / shakuna=勝気シャクナ
  mirine=満咲ミリネ / yuni=切熊ゆに / eru=百目鬼える / utsuro=氷室うつろ
  shano=幽麗シャノ / ritsu=依夢りつ / kataru=繰言かたる / tomoko=トモコ

■ 使い方
  いま入っているMP3は全部「無音の仮ファイル」です。
  録音した本物のボイスを、同じファイル名で上書きしてください。
  上書きした場面から、そのキャラのボイスが鳴るようになります。
  （4つのうち一部だけ本物でもOK。鳴るのは用意できた分からランダムです）

■ 注意
  旧形式の <ID>_plus.mp3 / <ID>_minus.mp3 も互換で使えます（番号付きが無い時だけ）。

📊 Googleスプレッドシート連携（セリフ） シートでも会話を編集できます。列は speaker / text（1行目はヘッダー）。3列目に fx 列を作って shake と書くと、その行で画面が揺れる演出が付きます。speaker は全キャラのID・名前（例: utsuro・氷室うつろ・うつろ）と narration（ナレーション）が使えます。連携シートが最優先で、無い場合は上のエディタ→内蔵デフォルトの順で再生されます。シートは「リンクを知っている全員が閲覧可」にしてね。
🎬 エンディング会話のセリフ ゲーム終了後に流れる会話シーンを編集できます。話者に「🏆 優勝者（ゴールした人）」を選ぶと、その対戦でカケラを集めてゴールした1位のキャラが喋ります。セリフの中に {winner} と書くと、1位のキャラの名前だけ（苗字なし）に置き換わります。フルネームで呼びたい時は {winner_full} と書いてください。{winner_h} と書くと敬称に置き換わります（通常は「ちゃん」、ヘル・シャクナが優勝者の時は「君」）。会話が終わると、順位順に立ち絵が並んだ結果画面に切り替わります。
📊 Googleスプレッドシート連携（エンディング会話） エンディング会話もシートで編集できます。形式はオープニング会話と同じ speaker / text / fx 列です。連携シートが最優先で、無い場合は上のエディタ→内蔵デフォルトの順で再生されます。シートは「リンクを知っている全員が閲覧可」にしてね。
🌸 Googleスプレッドシート連携（ひかり優勝時の専用エンディング） 優勝者が「神乃ひかり」の時だけ、通常の代わりにこのシートの会話が流れます。形式は speaker / text / fx 列で同じです。未連携の時は通常のエンディング会話になります。シートは「リンクを知っている全員が閲覧可」にしてね。
🧊 Googleスプレッドシート連携（うつろ優勝時・プレイヤー操作の時だけの専用エンディング） 優勝者が「氷室うつろ」で、そのうつろを操作しているのがプレイヤー（CPU戦の1P／オンラインの人間プレイヤー）の時だけ、通常の代わりにこのシートの会話が流れます。CPUのうつろが優勝した時は通常のエンディング会話になります。形式は speaker / text / fx 列で同じです。未連携の時は通常のエンディング会話になります。シートは「リンクを知っている全員が閲覧可」にしてね。
